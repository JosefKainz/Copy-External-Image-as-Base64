# Privacy Policy

**Copy External Images as Base64 Chrome Extension**

*Last Updated: November 12, 2025*

## Overview

This Privacy Policy describes how the "Copy External Images as Base64" Chrome Extension ("the Extension", "we", "our") handles data when you use our service. We are committed to protecting your privacy and being transparent about our data practices.

## Data Collection and Processing

### What Data We Process

The Extension processes the following types of data **locally in your browser only**:

- **Website Content**: Images and HTML content from webpages you visit
- **Clipboard Data**: Temporary access to content you copy using our extension
- **External Images**: Downloads images from HTTP/HTTPS URLs for Base64 conversion

### What Data We DO NOT Collect

❌ **Personal Information**: No names, email addresses, or personal identifiers  
❌ **Browsing History**: No tracking of websites you visit  
❌ **User Behavior**: No monitoring of clicks, scrolling, or typing  
❌ **Authentication Data**: No passwords or login credentials  
❌ **Location Data**: No geographic or IP address information  
❌ **Financial Information**: No payment or financial data  
❌ **Health Information**: No medical or health-related data  

## How We Use Data

### Purpose of Data Processing

The Extension has a **single purpose**: Converting external images to Base64 format when copying web content to your clipboard.

**Specific Uses**:
- Download external images from websites for Base64 conversion
- Process clipboard content to embed converted images
- Temporarily hold image data in browser memory during conversion

### Data Processing Principles

✅ **Local Processing Only**: All operations occur within your browser  
✅ **No Data Storage**: No persistent storage of any user data  
✅ **No Data Transmission**: No data sent to external servers (except fetching images for conversion)  
✅ **Temporary Processing**: Data is only held in memory during active use  
✅ **User-Initiated**: All processing occurs only when you actively use the extension  

## Permissions Explained

The Extension requests the following Chrome permissions:

| Permission | Purpose | Data Access |
|------------|---------|-------------|
| `contextMenus` | Creates right-click menu option | None - just adds UI element |
| `scripting` | Executes image conversion script | Temporary access to webpage content |
| `activeTab` | Accesses current webpage content | Images and HTML from current tab only |

**Note**: We do not request `clipboardRead` or `clipboardWrite` permissions as the modern Clipboard API works through user interaction without explicit permissions.

## Technical Details

### Data Flow
1. User activates extension via context menu
2. Extension accesses current webpage content
3. External images are fetched and converted to Base64 locally
4. Converted content is placed in clipboard
5. All temporary data is immediately discarded

### No Persistent Data
- **No Cookies**: Extension does not use cookies
- **No Local Storage**: No data saved to browser storage
- **No Cache**: No persistent caching of images or data
- **No Logs**: No logging of user activity or data
